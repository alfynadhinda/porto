# Portfolio — React 19 + Tailwind CSS v4 + Vite 7

Website portofolio & "open for work" dengan desain terinspirasi One UI (sudut sangat membulat, kartu bento, navigasi pill, mode gelap).

## Edit konten

Semua teks, project, skill, dan kontak ada di satu file: **`src/data.js`**.
Ganti `Nama Anda`, email, WhatsApp, username GitHub/LinkedIn, dan daftar project.
Judul tab browser ada di `index.html` (`<title>`).

## Jalankan lokal

```bash
npm install
npm run dev
```

## Versi yang dipakai

- React 19, Vite 7, Tailwind CSS 4 (plugin `@tailwindcss/vite`)
- GitHub Actions: `checkout@v5`, `setup-node@v5` (Node 24), `configure-pages@v5`, `upload-pages-artifact@v4`, `deploy-pages@v4`
